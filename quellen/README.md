# Quellenmaterial

| Ordner | Inhalt |
|---|---|
| [`notizen/`](notizen/) | Quellentabellen der Recherche-Agenten und der Projektleitung. Daraus wird [SOURCES.md](../SOURCES.md) erzeugt (`python3 tools/build_sources.py`). |
| [`pdf/`](pdf/) | Eigene PDF-Dateien (z. B. Handbuch, Lösungsbuch-Auszüge für den Eigengebrauch). Urheberrecht beachten: Inhalte nur zusammenfassen. |
| [`screenshots/`](screenshots/) | Eigene Screenshots von der PS5. Dateiname: `JJJJ-MM-TT_bereich_kurzbeschreibung.png`, z. B. `2026-11-30_einstellungen_zielhilfe.png`. |

## Regeln

- Jede neue Quelle bekommt eine ID (Präfix siehe [AGENTS.md](../AGENTS.md)) und eine Zeile in einer Datei unter `notizen/`.
- Wenn eine Seite nicht erreichbar war: `Erreichbar? = nein` eintragen und keine Inhalte daraus als geprüft ausgeben.
- Eigene Screenshots sind Belege mit Präfix `U`. Im Spiel selbst gesehene Menüs gelten als sehr gute Quelle für Einstellungen.
