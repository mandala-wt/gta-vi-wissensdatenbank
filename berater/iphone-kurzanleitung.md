# iPhone-Kurzanleitung: GTA-VI-Voice-Coach einrichten

> **Dauer:** ca. 15 Minuten, einmalig · **Du brauchst:** iPhone, AirPods, ChatGPT-Konto · **Stand:** 2026-11-26
> Ausführliche Fassung mit Begründungen: [voice-coach-anleitung.md](voice-coach-anleitung.md)

## ✅ Einmalig einrichten

**1. App bereit machen**
- ChatGPT-App aus dem App Store installieren bzw. aktualisieren und anmelden.

**2. Wissensdatei aufs iPhone holen**
- Auf GitHub (Safari oder GitHub-App) die Datei `berater/export/coach-paket-spoilerfrei.md` öffnen.
- **Raw** antippen → **Teilen** → **In „Dateien“ sichern**.
- Genauso mit `GESAMTANLEITUNG.md` verfahren.
- Tipp: Am Computer geht das bequemer. Ein Projekt, das du dort anlegst, ist auch auf dem iPhone da.

**3. Projekt anlegen**
- ChatGPT-App → Seitenleiste (☰) → **Projekte** → **Neues Projekt** → Name: `GTA VI Coach`.
- Falls gefragt: Memory auf **„nur Projekt“** stellen.

**4. Anweisungen einfügen**
- Im Projekt → **Anweisungen** → Text aus [system-prompt.md](system-prompt.md) einfügen (nur den Block im grauen Kasten).
- Darunter deinen ausgefüllten Steckbrief aus [spielerprofil-vorlage.md](spielerprofil-vorlage.md) einfügen.

**5. Dateien hochladen**
- Im Projekt → **Dateien hinzufügen** → **Dateien-App** → die beiden gesicherten Dateien auswählen.
- ⛔ **Keine** Dateien aus dem Ordner `spoiler/` hochladen.

**6. Sprache einstellen**
- ChatGPT → Einstellungen → **Sprache / Voice** → **Hintergrund-Gespräche** einschalten 🟡 (so laut OpenAI, Menüname kann abweichen).
- Eine gut verständliche Stimme wählen.

**7. Testen**
- Im Projekt einen **neuen Chat** öffnen → **Wellen-Symbol** antippen.
- Frage: *„Wie ziele ich in GTA 6?“* → Die Antwort sollte kurz und auf Deutsch sein.
- Bildschirm sperren und weiterfragen. Antwortet der Coach weiter, ist alles richtig eingestellt.

## 🎮 Vor jeder Spielsitzung (30 Sekunden)

1. AirPods einsetzen (mit dem iPhone verbunden).
2. iPhone ans Ladekabel. Der Sprachmodus braucht viel Akku.
3. Optional: **Nicht stören** im Kontrollzentrum einschalten, damit dich keine Mitteilungen stören.
4. ChatGPT → Projekt **GTA VI Coach** → neuer Chat → **Wellen-Symbol**.
5. Ersten Satz sagen, z. B. *„Ich spiele jetzt, Kapitel 2.“*
6. iPhone weglegen, möglichst nicht direkt neben den Fernseher. Los geht's.

## 🛟 Wenn etwas hakt

| Problem | Lösung |
|---|---|
| Coach reagiert auf Spielgeräusche | Fernseher etwas leiser, iPhone weiter weg vom Fernseher legen |
| Gespräch ist beendet | Nach längerer Stille beendet ChatGPT das Gespräch 🟡 → Wellen-Symbol erneut antippen (z. B. in einer Ladepause) |
| Antworten zu lang | Sagen: *„Kürzer bitte, maximal zwei Sätze.“* |
| Coach spoilert | Sagen: *„Keine Spoiler, ich bin in Kapitel …“*, und prüfen, dass keine Spoiler-Datei im Projekt liegt |
| Coach kennt die Projektdateien nicht | Prüfen, ob der Chat **im Projekt** gestartet wurde (nicht im normalen Chatverlauf) |

> 🟡 = laut Quelle, aber noch nicht selbst überprüft. Ab **11.12.2026** stellt OpenAI auf einen neuen Sprachmodus um. Danach diese Schritte kurz prüfen.
